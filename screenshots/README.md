## Screenshot Security Rules

Screenshots must not contain:

- Passwords
- Private API keys
- Live access tokens
- Private environment values
- Confidential employer information
- Real customer information
- Personal documents
- Unrelated desktop notifications

The Day 4 screenshots represent a local nonproduction PostgreSQL
environment. They do not represent direct access to the public
demonstration API database.
