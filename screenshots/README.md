## Screenshot Rules

Screenshots must not contain:

- Passwords
- API keys
- Access tokens
- Private connection strings
- Confidential employer information
- Real customer information
- Personal documents
- Unrelated desktop notifications

The screenshots represent a local nonproduction PostgreSQL environment.
They do not represent direct access to the public demonstration API
database.
