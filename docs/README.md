# Project Documentation

This folder contains supporting documentation that is useful for project
history but is too detailed for the recruiter-focused root README.

## Files

- [Project Development Journal](project-development-journal.md)
- [Main Project README](../README.md)

## Purpose

The root README presents the project overview, major results, evidence
and current status.

The development journal preserves the chronological Day 1 through Day 5
history, including the state of the project before execution began.
Historical `Not Run` and draft statuses are retained only inside the
journal and are clearly identified as the status at that time.
